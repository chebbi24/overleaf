\section*{Required execution order}

The frozen sequence is: run the local provider smoke gate; capture the runtime manifest; execute PLT LIVE; audit and hash evidence and traces; execute PLT REPLAY; execute Skywork; execute the direct judge; join the persisted outputs to Human Gold; evaluate the deterministic external samples; compute pre-declared metrics; and only then select trace-backed examples for qualitative discussion.

No semantic prompt, rubric, decision rule, model, target/search budget or source-exclusion policy may be changed after the semantic freeze in response to evaluation outcomes. Execution-only failures may be rerun with unchanged code and configuration and must remain documented.

\section*{Artifact inventory}

The final reproducibility archive must preserve the canonical PLT file and manifest, raw and derived Human Gold artifacts, \texttt{final\_manifest.json}, \texttt{final\_vericult\_config.json}, runtime manifest, LIVE and REPLAY summaries, all candidate traces, the evidence freeze manifest and snapshots, Skywork/direct-judge outputs, deterministic external-validation selections, statistical-analysis outputs, figure-generation scripts and the exact thesis source used for submission.

The 120-item cross-dataset validation is preserved separately from the active final-experiment tree on repository branch \texttt{archive/external-120-pre-freeze}; immutable corpus/result snapshot \texttt{3a7bd8088ca1f9cabc8b7945792430cc501c160d}, current provenance-metadata head \texttt{fd844af0e402dd32af60c2a9c69c4344216df59a}. Its final failed-item rerun used the October 5 repaired result semantics that have now been restored into final Vericult 1.1. The archive contains:

\begin{itemize}
    \item \texttt{data/evaluation/external\_120\_pre\_freeze/prompt\_response\_pairs\_120.txt}: the exact source-grounded corpus;
    \item \texttt{data/evaluation/external\_120\_pre\_freeze/results\_final\_merged.jsonl}: the final post-rerun result export with 120 records;
    \item \texttt{data/evaluation/external\_120\_pre\_freeze/summary.json}: aggregate counts, per-dataset statistics and unresolved-case diagnostics; and
    \item \texttt{README.md}: interpretation and version-separation notes.
\end{itemize}

This branch is archival only. It preserves empirical inputs/results and does not change the active semantic freeze. The compact result export does not embed the exact runtime Git SHA, so the run remains identified as pre-freeze empirical validation even though its result semantics match the restored final verifier.
