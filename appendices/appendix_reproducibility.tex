\section*{Required execution order}

The frozen sequence is: run the local provider smoke gate; capture the runtime manifest; execute PLT LIVE; audit and hash evidence and traces; execute PLT REPLAY; execute Skywork; execute the direct judge; join the persisted outputs to Human Gold; evaluate the deterministic external samples; compute pre-declared metrics; and only then select trace-backed examples for qualitative discussion.

No semantic prompt, rubric, decision rule, model, target/search budget or source-exclusion policy may be changed after the semantic freeze in response to evaluation outcomes. Execution-only failures may be rerun with unchanged code and configuration and must remain documented.

\section*{Artifact inventory}

The final reproducibility archive must preserve the canonical PLT file and manifest, raw and derived Human Gold artifacts, \texttt{final\_manifest.json}, \texttt{final\_vericult\_config.json}, runtime manifest, LIVE and REPLAY summaries, all candidate traces, the evidence freeze manifest and snapshots, Skywork/direct-judge outputs, deterministic external-validation selections, statistical-analysis outputs, figure-generation scripts and the exact thesis source used for submission.
