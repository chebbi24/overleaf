\section*{Required execution order}
The final execution order follows the experimental methodology chapter: validate the final architecture; choose the backbone on development material; freeze Vericult; generate and annotate v2 without Vericult-based filtering; acquire and freeze LIVE evidence; execute primary REPLAY evaluation; run independent baselines; run external validation; then compute comparative statistics and qualitative trace analysis. No semantic tuning is permitted after the verifier freeze.

\section*{Artifact inventory}
The final submission archive should contain, or provide stable repository references to, v1 and v2 datasets, generator-provenance mappings, annotation exports, the experiment manifest, verifier traces, evidence schedules/snapshots, baseline outputs, external-validation selections, statistical-analysis outputs, figure-generation scripts, and the exact thesis source used for submission.
